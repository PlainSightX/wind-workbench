# 精选结果

## 预测方法

Q1历史代理数据采用事前时间切分，Ridge正式3885行MAE从197.534降至183.187，下降7.26%，
RMSE下降9.22%。小型Transformer确实完成训练与模型交付，但没有采用；低变化组Ridge仍落后于持久性。
开发选择和正式评价属于不同阶段；见 [完整Q1比较](WIND-SEQUENCE-RESULTS.md)。

ENGIE四机组420480行质量审查后，以持久性、Ridge和LightGBM作滚动比较。
共享收缩在2014三个开发季度的等季度MAE改善1.80%，未达到冻结3%采用门，默认保持持久性。
冻结后一次2015评价MAE改善2.985%、RMSE改善4.038%；2015已经曝光，不能继续当新方案盲测。
见 [开发原文](results/wind-engie-a2-20260923/README.md) 与 [最终原文](results/wind-engie-a3-20260923/README.md)。

这些是同一历史场景的离线对照，不是跨场站泛化、客户收益或中国电网效果。
51072个可评分起报也不是51072个独立样本。

## 工程与问答

任务登记、outbox、租约和attempt条件防止投递与worker故障造成错误完成；模型包版本进入历史回放。
W1新空卷实例完成真实Q1实验和六次预测；原ENGIE五模型各51200个合法输入CPU回放与原预测一致，
最大差异约4.55e-13 kW，另外15个HTTP窗口核对发布、幂等和重启读回。这是复现证据，不是新精度提升。

已有有限负载1080个核心尝试中932个正确接受、148个容量拒绝，无非预期HTTP或身份/数值错误；
容量拒绝是边界，不应写成全部请求成功。该数据只证明当时硬件和有限工作负载。

结果助手的已见24题开发比较为关键词24/24、向量23/24、完整上下文22/24。
曾经出现“事实列表正确、正文没有回答阶段问题”，之后补阶段正文校验并用原两问及两个固定变体复核。
这些数量不能包装为开放问答准确率，机器数字绑定也不能代替语义判断。

新空卷W2实例的当前实现已完成全部软件组、两个原附件组及桌面/移动浏览器。
四题真实HTTP确认批次语义复核通过，但此前同一Q1问题曾在一次修复后因数字未绑定而拒答；
保留该首次负结果，不声称首次4/4或稳定性已证明。另一个新Ridge对象回答正确绑定自己的
MAE并明确开发结果不证明正式留出成功。具体范围见 [W2记录](public-release-w2.md)。

源码中的冻结JSON/CSV是来源锚与回归输入，不是训练日志。
精选原报告保留原字节；其中指向私人工作包的历史路径只说明出处，不要求外部重建该布局。
首发 v0.1.0 已公开，其远端结果以对应 Actions 为准；后继维护源码和本地候选不能借用
首发CI成绩。原模型附件不重新训练、改写或打包，来源与许可说明继续随附。

## 固定模型的延迟实况评价（维护增量）

预测先落账，实况按模拟到达时间进入逐起报/时距残差账本，普通HTTP和CLI给出
持久性主用与候选影子的滚动比较。[W1历史回放](results/wind-monitor-w1-20261005/README.md)
完成144次起报、864组成对时距记录，真实PG、独立CLI与TCP进程重启验证可续跑。
20分钟到达为模拟，2015为已见数据；没有新精度、生产漂移或自动切换的结论。

[W2缺测案例](results/wind-monitor-w2-20261006/README.md)把当前窗口成对样本、
待到达、到期缺测、无效输入和预测失败与MAE并列。受控补齐窗口外实况后，累计成对数
22→23、窗口仍11/12且MAE不变；补齐窗口内实况才达到12/12。重复补齐与应用重建读回一致。
缺测为测试注入；这是评分依据可解释性，不是新检测算法或缺测率改善。
