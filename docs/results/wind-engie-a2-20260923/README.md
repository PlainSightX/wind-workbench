# ENGIE A2：L1训练与共享收缩对照

本轮得到正向开发结果：把LightGBM训练目标从平方误差改成绝对误差后，等季度全场
MAE相对旧LightGBM降低7.83%。按事前固定规则加入持久性收缩后，MAE相对持久性
降低1.80%，三个季度均改善，RMSE降低3.35%。改善尚未达到事前规定的3%开发采用门，
因此保留候选，不替换工作台默认模型。2015保留期未评分，不能称独立泛化结论。

这是模型机制对照轮，接在[A1同包接入](../wind-engie-service-a1-20260923/README.md)
之后。当前页面仍使用A1的九个原包；新候选的正式留出与最终包接入属于后续A3。

## 问题与实际改造

旧LightGBM以MAE做早停，却以平方误差训练。评价指标名称相同不等于训练目标相同。
本轮仅将`objective=regression`改成`regression_l1`；这里L1是绝对误差损失，不是
Lasso正则。仍使用自身12条历史、相同四机组/六时距、400树上限、seed42与两CPU线程。
每台机组/时距分别训练，最后按四台功率合计评分；单机L1并不直接等于最小化全场MAE。

第二项是预登记的保守修正：

```text
输出 = 持久性 + lambda * (L1候选 - 持久性)
lambda ∈ {0, 0.25, 0.5, 0.75, 1}
```

每季度在内层28天按全场MAE选一个共享值，所有机组/时距共用，并列选更小值。
内层也用于早停，所以这是选型，不称独立校准。三个季度的内层预测和选择全部封存后，
才用边界前可得数据重拟合并评分外层。没有用已包含内层数据的最终模型倒查lambda，
没有按未来变化分组选择预测。旧Ridge、L2和持久性逐点输出直接复用，不增加原模型拟合。

## 同条件结果

主指标是三个季度等权平均的四机组合计、六时距raw kW误差，负值不裁剪。

| 模型/策略 | MAE (kW) | RMSE (kW) | 平均偏差 (kW) | MAE相对持久性改善 |
|---|---:|---:|---:|---:|
| 持久性 | 389.317 | 652.989 | -0.176 | 参照 |
| 原Ridge | 411.225 | 628.283 | +46.437 | -5.63% |
| 原LightGBM L2 | 418.720 | 645.504 | +60.704 | -7.55% |
| LightGBM L1直接输出 | 385.936 | 631.294 | -40.129 | +0.87% |
| L1＋内层选择的共享收缩 | 382.310 | 631.110 | -38.126 | +1.80% |

| 外层季度 | 持久性MAE | L1直接MAE | 内层所选lambda | 收缩MAE | 收缩相对持久性改善 |
|---|---:|---:|---:|---:|---:|
| 2014 Q2 | 431.068 | 438.859 | 0.5 | 425.122 | 1.38% |
| 2014 Q3 | 338.278 | 322.707 | 0.5 | 325.566 | 3.76% |
| 2014 Q4 | 398.606 | 396.241 | 1.0 | 396.241 | 0.59% |

Q3收缩反而略差于直接L1：内层选择不会保证外层最优。报告保留原选择，没有看到外层
后将Q3改成lambda=1。六个时距的等季度MAE均改善，但这不表示每个季度的每个时距都赢。

| 起报分母 | 数量 |
|---|---:|
| 三季度计划起报 | 39,600 |
| 合法输入且实际输出完整曲线 | 39,225 |
| 可评分起报 | 39,119 |
| 合法但事后标签不完整/受保留期边界保护 | 106 |

五种策略使用同一起报、输入/标签掩码和目标数组，完整覆盖均相同。106次仍实际输出，
不能因为缺未来标签提前拒绝预测。覆盖是离线输出事实，不是线上按时交付率。

## 改善发生在哪里，代价是什么

分组沿用原合同，阈值只取各季度训练段；下表也是等季度全场MAE。大小变化和低出力
分组使用事后目标，仅供诊断，不能直接成为上线时的门控条件。

| 分组 | 持久性 | 原L2 | L1直接 | L1共享收缩 |
|---|---:|---:|---:|---:|
| 大变化 | 1025.957 | 923.035 | 920.742 | 951.710 |
| 较小变化 | 235.489 | 296.224 | 256.283 | 245.172 |
| 低实际出力 | 117.958 | 208.252 | 133.851 | 125.694 |

L1显著减少旧L2在较小变化/低出力上的损失；收缩进一步接近持久性，但这些组仍输给
持久性。大变化组仍优于持久性，但部分学习模型优势被收缩削弱。平均偏差从旧L2的
偏高转为约38kW的偏低，不能把主指标改善解释为所有性质同时改善。

这些结果支持“训练目标和持久性修正值得区分”的机制判断；没有做L2收缩消融，不能
声称L1与收缩之间存在已证明的独特协同，也不能据此断言原问题只有一个根因。

## 采用决定与下一轮

事前协议要求：至少两个季度改善、平均MAE改善至少3%、最差季度回退不超过2%、
平均RMSE不恶化、完整覆盖不降。两种新策略只有“平均MAE至少3%”未通过。
这3%是本项目的投入/采用门槛，不是行业标准或统计显著性线；本轮没有事后放宽。

**本轮结论：机制有改善，默认采用门未通过，A2已完成。** 模型包和逐点预测保留，
工作台继续保持原默认，不把1.80%写成已验证的2015收益或生产收益。

建议下一轮进入原计划A3：冻结L1直接/内层共享收缩规则，保留持久性与原配方参照，
在2015保留期作一次最终评价；随后把实际评分的最终包经A1路径交付，并完成正常/
故障对照。先在揭示2015前固定比较成员、时间块区间和预算，失败不重开调参。
候选未通过开发采用门的状态必须保留，不能靠正式期挑一张好表追认采用。

不建议现在细化lambda或换神经架构。现有分组说明取舍，却没有证明另三台历史能补上
剩余误差；条件信息增量分支仍保留，未执行也未被否定。本次不为启动它额外增加拟合。
Stage C结果助手与用户主动失败重跑结对继续保留，不成为本轮完成的隐藏门槛。
